# ADR-0002: 授權與訂單使用非對稱簽章（ed25519），不用 HMAC

- 日期：2026-10-21
- 狀態：採納

## 背景
HMAC 快 10–100 倍，有人會提議訂單用 HMAC。

## 決定
授權與訂單一律用簽章。v0 用 ed25519；透過 `Signer` 介面抽象，ZK 階段內層換 Baby Jubjub EdDSA。HMAC 只用於簽名器內部（nonce 帳本、日誌完整性）。

## 選項與取捨
| 選項 | 優點 | 缺點 |
|---|---|---|
| HMAC | 快 | 驗證者可偽造；無不可否認性；subject 公鑰無法綁定；v1 合約／v2 ZK 走不通 |
| 簽章（採納） | 第三方可驗；鏈可接；不可否認 | 慢（但 50 µs vs API 數十 ms，可忽略） |

## 後果
- 規則：驗證者與簽發者是同一方才可用 HMAC。
- 關聯不變量：INV-11。
